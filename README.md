# 11-天予恒成官网

- 一句话用途：成都天予恒成科技有限公司企业官网（纯静态多页站），对外讲清「企业 AI 落地服务商」的定位、运营体系、服务流程与价目、产品矩阵、行业案例。
- 当前版本 / 最后更新：v1.5 / 2026-11-12（安全加固：开发文档不再随站点发布，站点只公开对外内容）
- 线上地址：https://tyhctech.com/
- 本地预览：在项目根目录执行 `python -m http.server 8788` → http://127.0.0.1:8788/
- 技术形态：纯静态 HTML + CSS + 原生 JS，无框架、无第三方依赖、无外部资源请求；托管 GitHub Pages
- 历史版本：变更记录维护在项目内部文档中，不随站点发布

## 页面结构

| 文件 | 内容 |
|---|---|
| index.html | 首页：主标语、五层定位、三道门槛、交付三件套、产品矩阵速览、联系 |
| about.html | 关于我们：公司概况与资质、我们是谁、五层定位表 |
| solution.html | 运营体系：AI 控制中心总控七层、数字员工治理五件套 + 五项 KPI、四级权限与熔断 |
| products.html | 产品矩阵：按六大业务环节组织（获客引流 / 售前交付 / 生产与业务执行 / 内部协同管理 / 风控合规与文档资产 / 复盘与数据运营），算力与治理单列为贯穿六段的底座 |
| service.html | 服务与价格：L0–L6 服务流程、五档服务包、六项合作保障 |
| cases.html | 行业案例：四大行业实践表、四个 FDE 脱敏案例 |
| 404.html | 404 兜底页（noindex，不泄露内部信息） |
| style.css | 全站共享样式（深蓝黑 + 电光青 / 紫，移动优先） |
| app.js | 移动端导航开关（唯一交互） |
| robots.txt / sitemap.xml / CNAME | 收录声明、站点地图、自定义域名 |
| security.txt / .well-known/security.txt | 漏洞报告联系方式（RFC 9116） |

## 内容口径

主体内容取自公司简介资料，逐条化用，不新增编造数据；资质、案例数字与原文一致。

产品矩阵的清单按公司确认的业务口径组织，只列已具备交付能力的产品与方案；每项标注交付形态与适用岗位，不做销售状态标注。

## 维护约定

- 本仓库只发布站点资源。项目记忆、变更记录等开发文档留在项目内部，不进入发布范围。
- 页面改动后必须逐页做视觉核验与 HTML 标签闭合校验，不能只看源码。
- 对外文案统一书面表述，不使用口语化、拟人化说法。
